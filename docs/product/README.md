# Code-role Product Docs

This folder contains product-level documents for Code-role.

- [v0.2 Goal Loop / v0.2 目标闭环](../loop/README.md): current default product and operating model.
- [中文产品需求对齐稿](prd.zh-CN.md): 用于需求对齐、范围确认和迭代讨论。
- [PRD](prd.md): product direction, target users, MVP scope, requirements, non-goals, and open decisions.
- [中文 HTML 说明与初始化指南](code-role-workflow-guide.zh-CN.html): 用于外发介绍、配置说明和项目初始化指引。

The PRD and HTML guide describe the legacy eight-role profile unless a section explicitly says v0.2. New project initialization should follow the goal-loop guide.

PRD 与 HTML 指南仍主要描述历史八角色模式；除非章节明确标为 v0.2，新项目初始化应以目标闭环说明为准。
